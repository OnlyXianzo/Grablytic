# Security Policy

[`docs/security.md`](docs/security.md) has the full policy: what is stored,
what leaves the device, and the threat boundaries. This page is the short
version GitHub links from the Security tab.

## Supported Versions

Only the latest release of Grablytic receives security updates.

| Version | Supported |
| ------- | --------- |
| 0.0.x   | :white_check_mark: |
| < 0.0.1 | :x: |

## Reporting a Vulnerability

Do not open a public issue, a discussion, or a pull request for a
vulnerability.

Report it privately through [GitHub Private Vulnerability
Reporting](https://github.com/OnlyXianzo/Grablytic/security/advisories/new).
If you cannot use that, email <xianzo.help@gmail.com> instead.

Include:

- What the vulnerability is and what an attacker gains from it.
- Steps to reproduce, or a proof of concept.
- The platform (Android version, or the desktop OS), the architecture, and
  the Grablytic version you tested.

A report is acknowledged within 48 hours, and a fix is coordinated with you
before anything is published.
