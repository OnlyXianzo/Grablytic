## v0.0.4 — 2026-09-17 (huge improvement release; 118 commits since v0.0.2)

- **System player**: finished downloads open in the device video player
  (`FileProvider` + `intent/open_file` channel with MIME fallback); desktop
  opens via OS resolver.
- **Resume that works**: `writeinfojson` default-ON so interrupted downloads
  leave a URL sidecar for one-tap resume (cleaned on success); partials
  stream straight to the output dir (no more cache-eviction crashes);
  FFmpeg merges serialized (no thermal freeze) with a 600s hung-merge guard.
- **Concurrency guard**: slider warns above 2 simultaneous downloads
  (battery/thermal); default follows CPU cores. Desktop IPC threaded —
  slow extractions no longer block cancel; longer budgets for
  formats/playlist/search.
- **Links that open**: external links use try/catch instead of
  package-visibility-blocked `resolveActivity`; deep-link filter for shared
  URLs; legacy `Download/TrueStream` auto-renamed to `Download/Grablytic`.
- **Library grids + onboarding**: playlists and history honor the grid-view
  toggle; permissions beat unified with the dark onboarding design.
- **Log viewer survives big logs**: capped tail render (100KB/1000 lines)
  with truncation banner — 4–5MB logs no longer hang the phone; level
  filter cancellation fixed.
- **Security**: SSRF guard closed for hex/octal/decimal IP spellings and
  DNS-rebinding hostnames; phantom per-download PO-token spawn gated off;
  installer publishes `SHA256SUMS` (fail-closed, API-digest fallback);
  shell-injection closed.
- **Android lifecycle**: terminal events survive activity death; wakelock
  renewal + timeout sweep; active downloads cancelled on FGS timeout;
  atomic package extraction with CRC stamps; Kotlin SQLite access
  serialized with busy-timeout/retry.
- **Perf**: throttled progress at source, bounded queues, single-card
  rebuilds, bundled Instrument Sans (no runtime webfont fetch).
